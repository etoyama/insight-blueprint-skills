# ADR-0056: 答えの変化は引用の差から導き、上の論点と先の論点の両方のカードに出す

## Status

Accepted

## Context

Epic 34（[#249](https://github.com/etoyama/insight-blueprint-skills/issues/249)、[DesignDoc](../design/epic-34-what-moved-the-answer.md)）の初版で決めた。
論点ツリーで複数の論点を調べると、後から届いた論点の結果が、先に出た結果の使われ方を変えることがある。
先に出た結果の数値と、その論点の答えは変わらない。変わるのは、上の論点の答えがその結果を引用する文である。

比較の土台にした事実（epic ブランチ dc785c4。`scripts/handoff_trial.py` の `build` に架空のシナリオを通し、HTML を読んだ）。

- 論点 B の答えに、後の論点 C の出来事を引用すると、`tree_io answer` は `unlinked-design` を返し、何も書かない。主題は論点ツリー全体の出来事を引用できる（`QuestionTree.designs_by_branch`）。
- 答えは回ごとに全文を持ち、文ごとに種類と引用を持つ（`Answer.statements`）。前の回もすべて YAML に残る。同じ文なら `tree_io answer` は書かない。
- 答えが変わった論点のカードには「回 N で変わった」とだけ出る。印は最新の回の答えにだけ付き、回が進むと消える（`tree_render` の `marks_of`）。
- 差が出なかった分析の回で、主題の答えを書き直さないと、その回の証拠を主題の答えが引用していないことは、どこにも出ない。
- 1つの回で、後の論点の2つの証拠が先の2つの論点の引用のされ方を変えるシナリオも通った。主題の答えには両方を書けた。
- 文の差からは言い換えと撤回を区別できない。

## Problem

- 課題1: 先に調べた論点のカードを開いた人は、上の論点がその結果を引用する文を変えたことに気づけない。古い読み方のまま数値を持ち帰る。
- 課題2: 答えが変わった回で、何が変わったかは、前の回の答えと今の答えを目で比べるしかない。引用をやめた証拠は今の答えから消え、消えたことは表示に出ない。
- 課題3: 差が出なかった分析の回では、上の論点の答えが書き直されないことがある。結果を上の答えに突き合わせたのかが読めない。

扱わない範囲: ツリーの決定の理由の引用（[ADR-0058](0058-a-tree-decision-may-cite-the-events-behind-its-reason.md)）。答えの変化をレポートに出すこと。

## Decision Analysis

決めることは2つある。変化をどこに書いてどこに出すか（判断1）と、何が変わったかを導くか書かせるか（判断2）である。

| # | 基準 | 区分 | 分類 | 重み（決めた人） | 出典 |
|---|---|---|---|---|---|
| M1 | 保存済みの論点ツリーの YAML がそのまま読める | Must | - | - | 不変条件（正本は YAML） |
| M2 | 表示が、記録に無いことを言わない | Must | - | - | [ADR-0025](0025-cited-answers-checked-after-writing.md) |
| W1 | 先の論点のカードから変化に辿れ、何が変わったかを目で比べずに読める | Want | 解決 | 高（人間） | 課題1、課題2 |
| W2 | 上の答えに突き合わせていない結果が見える | Want | 解決 | 高（人間） | 課題3 |
| W3 | ツリーの検査の守りを保つ | Want | 費用 | 高（Claude の推測） | ADR-0025 |
| W4 | 書き手の手間と、書き間違いの余地 | Want | 費用 | 中（Claude の推測） | ADR-0025 の Negative |

判断1 の案。

- 案1A: 変化は共通の上の論点の答えにだけ書く。表示が先の論点のカードへ逆向きに出す。検査は変えない。
- 案1B: `unlinked-design` を緩め、先の論点の答えに後の論点の出来事を引用して書き直せるようにする。
- 何もしない。

判断2 の案。

- 案2A: 前の回と今の回の引用の差から導く。証拠ごとに、前の回の文と今の回の文を並べる。
- 案2B: 答えに「動かした証拠」「取り下げた主張」の項目を足し、書き手が埋める。
- 案2C: 案2A に加え、文に「前の回のこの文の言い換え」という任意の項目を足す。
- 何もしない。

| Must | 案1A | 案1B | 案2A | 案2B | 案2C |
|---|---|---|---|---|---|
| M1 | 満たす | 満たす | 満たす | 満たす | 満たす |
| M2 | 満たす | 満たす | 満たす | 満たさない恐れがある。「取り下げた」は書き手の申告で、検査できるのは引用の有無までである | 満たす |

| Want | 案1A | 案1B |
|---|---|---|
| W1 | 辿れる。先の論点のカードに、上の論点のどの回のどの文かが出る | 辿れる。先の論点の答えそのものに書かれる |
| W3 | 保つ | 崩れる。どこまで許すかの線を引き直す必要があり、無関係な分析の数値を引いた答えが通る |
| W4 | 書くのは1か所（上の論点） | 2か所。片方だけ直すと食い違う |

| Want | 案2A | 案2C |
|---|---|---|
| W1 | 読める。言い換えただけの文も「文が変わった」に出る | 読める。言い換えは畳める |
| W2 | 見える | 見える |
| W4 | 手間なし | 書き手が印を付ける。撤回を言い換えと申告できる |

- 差がつく基準: 判断1 は W3 と W4。判断2 は W4 と、W1 の言い換えの雑音。
- 感度: 判断1 は、W3 を低にしても W4 で案1A が残る。先の論点の問いへの答えは変わっていないので、置き場も上の論点が合う。判断2 は、言い換えの雑音が実際に多ければ案2C に傾く。案2A から案2C へは項目を足すだけで移れる。

| 案 | 起きうる悪い結果 | 抑え方 |
|---|---|---|
| 案1A | 上の論点の答えが先の論点の証拠を引用しないと、逆向きに何も出ない | 引用していない下の結果を表示する（Decision の4） |
| 案1B | 検査が緩み、別の分析の数値を流用した答えが通る | 線の引き直しと守りのテスト。費用が大きい |
| 案2A | 言い換えが多く、変わった所が埋もれる | skill に「変えない文は前の回のまま書く」と書く。試行で雑音を数える |
| 案2A | 因果は出ない。出るのは「同じ回に新しく引用された」までである | 見出しを「前の回から変わったこと」にし、「動かした」と言い切らない |
| 案2B | 申告が事実と食い違い、表示が記録に無いことを言う | 検査を厚くする。費用が大きい |
| 案2C | 撤回を言い換えと申告して隠せる | 印の付いた文も開けば読めるようにする |
| 何もしない | 課題1〜3 が残る | 無い |

## Decision

案1A と案2A を採る（人間の判断、2026-11-26）。決め手は、判断1 が W3 と W4、判断2 が M2 と W4 である。

1. 後から届いた結果で読み方が変わったことは、共通の上の論点の答えにだけ書く。先の論点の答えは書き直さない。
2. ツリーの検査は変えない。論点が引用できるのは、自分と下の論点に結んだ分析設計の出来事だけである。
3. 答えの変化（`AnswerChange`）は、論点の最後の答えと、その1つ前の答えから導き、保存しない。引用する出来事ごとに、前の回の文と今の回の文を並べ、4つに分ける。
   - 新しく引用した: 前の回の答えに無く、今の回の答えにある出来事。
   - 引用をやめた: 前の回の答えにあり、今の回の答えに無い出来事。
   - 同じ出来事を引用する文が変わった: 両方にあり、引用する文（種類と本文）の集まりが違う出来事。
   - 変わっていない: 両方にあり、引用する文が同じ出来事。表示では畳む。
4. 引用していない下の結果（`UncitedBelow`）を導く。下の論点の現時点の答えが引用していて、その論点の現時点の答えが引用していない出来事である。次の2つに分けて出す（見本への人間の指摘、2026-11-26）。
   - その論点の答えが一度も引用していない出来事。分析者に判断してほしいものとして目立たせる。差が出なかった分析の結果は、ここに出る。
   - 前の回までは引用していて、今は引用していない出来事。控えめに出し、最後に引用した回と、引用をやめた回に新しく引用した出来事を添える。
5. 上の論点での引用（`CitedAbove`）を導き、先の論点のカードに出す。論点の現時点の答えが引用する出来事を、上の論点の現時点の答えが引用している所である。上の論点がその出来事を引用する文を、この論点の答えより後の回で変えていれば、カードはそれを文で出す。
6. 答えの変化は最新の回のものでなくても論点のカードに出す。答えが最新の回のものでないときは、答えの回と最新の回を並べ、その後の回で書き直していないことを出す。
7. 表示は導いた事実だけを言う。「答えを動かした証拠」「消えた主張」とは言い切らない。見本（画面3）からの後退として、人間が受け入れた。行の中心には出来事の本文を置き、前の回にそこから言っていた文と、今の回の文を並べる。分析者に見せる言葉は [ADR-0055](0055-the-root-question-is-shown-as-the-subject.md) に従う。
8. `/analysis-reflection` は、変えない文を前の回のまま書く。ツリーの決定を聞く前に、引用していない下の結果を分析者に見せる。引用するかは分析者が決める。

## Consequences

### Positive

- 正本の形を変えずに、この Epic の前に書かれた論点ツリーにも効く。
- 表示が言うことは、すべて YAML と journal から導ける。書き手の申告に頼らない。
- 差が出なかった分析の結果が、上の論点のカードに「引用していない結果」として残る。

### Negative

- 言い換えただけの文も「文が変わった」に出る。雑音が多いかは、引き継ぎの試行で確かめる。多ければ、文に言い換えの印を足す案（案2C）を別の決定で足す。
- どの証拠が答えを動かしたかの因果は出ない。読み手は新しく引用した証拠と、弱める証拠の文から読み取る。
- 上の論点の答えが先の論点の証拠を引用しなければ、先の論点のカードには「上の論点の答えは引用していない」としか出ない。
- 引用をやめた理由（より強い根拠が出た、など）は記録に無く、表示は言わない。引用をやめた回に新しく引用した出来事を並べ、読み手が読み取る。
- 答えに入れないと決めた結果と、まだ見ていない結果は、記録では区別がつかない。入れないと決めた結果は目立つ欄に残り続ける。巡回のたびに聞かれて煩わしいと分かったら、入れないと決めたことを記録する項目を別の決定で足す。
- 2つ前より古い回との差は出ない。前の回の答えは今までどおり畳んだ中で読む。
- 数を含まない言い過ぎは今までどおり検査を通る（ADR-0025 の Negative のまま）。

## Alternatives considered

- **文の本文の近さで言い換えを見分ける** — 近さのしきい値に根拠が無く、撤回を言い換えと出す誤りを表示が作る。M2 を満たさない。
