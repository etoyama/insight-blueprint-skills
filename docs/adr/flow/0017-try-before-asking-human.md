# FLOW-0017: 人間に判断を仰ぐ前に、30分以内に試せることは試し、結果を添えて聞く

## Status

Accepted

## Context

[FLOW-0004](0004-decision-analysis-plugin.md) は、人間に判断を仰ぐときの提示を Decision Analysis の形式にそろえた。
発動の条件は「選択肢が2つ以上あり、既存の決定から一意に決まらない」などで、案を試せるかどうかは問わない。
[docs/WORKFLOW.md §6](../../WORKFLOW.md) と PM セッションのスキル `.claude/skills/pm-session/SKILL.md` にも、聞く前に試す決まりは無い。

このテンプレートの派生先の Epic 34（etoyama/insight-blueprint-skills、[#249](https://github.com/etoyama/insight-blueprint-skills/issues/249)、2026-11-26）で、
次のことが起きた。振り返り（#249 の[コメント](https://github.com/etoyama/insight-blueprint-skills/issues/249#issuecomment-7185439265)）で確かめた。

- 表示を変えた直後の試行で、点が落ちた問題が2つ出た。合成シナリオの2つ目の質問は9回のうち3回しか正解せず、4つ目の質問は読み手のモデルの1つが4回外した。
- PM は、直し方の案を Decision Analysis で並べ、人間に選んでもらおうとした。
- 人間が「質問を直して、正答するかを確かめたら」と言った。試すと、質問の言い直しで6回とも正解し、決まりを1行変えた写しで9回とも正解した。かかったのは30分だった。
- 案を並べた表より、試した結果のほうが根拠が強かった。

## Problem

- 課題1: 試せば決まる判断を、案の比較として人間に渡すと、人間は結果を見ずに選ぶことになる。選んだ後に試して外れると、聞き直しになる。
- 課題2: 聞く前に試すかどうかが AI の思いつきに任されると、判断ごとにぶれる。
- 課題3: 何でも試してから聞くと、人間の待ちが延びる。試すことが、戻しにくい変更になることもある。

扱わない範囲: Decision Analysis の形式そのもの（正本は decision-analysis プラグイン）。試す方法（成果物の種類ごとに違う）。

| 案 | 起きうる悪い結果 | 抑え方 |
|---|---|---|
| A | 30分の見積もりが外れ、試すのが長引く | 30分を過ぎたら止め、そこまでの結果を添えて聞く |
| A | 試すために、戻しにくい変更をする（外に出す、利用者のデータを書き換える） | 試すのは、手元で元に戻せることだけにする。戻せないなら、試す前に聞く |
| A | 試した結果を理由に、人間に聞かずに進める | 結果が出ても、判断は人間に仰ぐ。試すのは、聞くのをやめる理由にならない |
| B | 試すのが終わらず、判断がいつまでも人間に届かない | 上限が無いので抑えられない |

## Decision

A を採る。定義の正本は WORKFLOW §6 に置き、PM と子の回し方は pm-session §5 とブリーフの型に置く。

- 人間に判断を仰ぐ前に、30分以内に試せることは試す。聞くときに、何を変え、何回確かめ、どうなったかを添える。
- Decision Analysis は、試しても決まらない判断（好み、方針、費用と効き目の釣り合い）に使う。試した結果は、Problem の「前提にした事実」に書く。
- 試すのは、手元で元に戻せることだけにする。30分を過ぎたら止め、そこまでの結果を添えて聞く。

人間が束 A として採った（派生先の Epic 34 の振り返り、2026-11-26）。決め手は M1 と W1。

## Consequences

### Positive

- 人間は、案の比較ではなく、試した結果を見て決められる。
- 試して決まる判断では、聞き直しが減る。

### Negative

- 30分で試せるかの見積もりは AI に任せる。試せるのに試さずに聞くことを、機械的には止められない。
- 試す分だけ、人間に聞くのが遅れる。
- 根拠は1件（Epic 34 の試行）だけである。

## Alternatives considered

- **decision-analysis プラグインの形式に「試した結果」の欄を足す** — 形式の正本は別のリポジトリにあり、このテンプレートを使わない利用者にも効く。試すかどうかはフローの決まりなので、こちらに置く。
